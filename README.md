This repository contains the production-ready distribution files for **HRIS**. This build has been optimized for low latency, high performance, and cross-browser compatibility.

---

## ⚡ Deployment Overview

This is a **compiled static site**. It does not require a Flutter environment to run. The distribution includes:
- Minified JavaScript bundles (`main.dart.js`).
- Pre-compiled CanvasKit WebAssembly modules.
- Progressive Web App (PWA) service workers and manifest.
- Optimized asset tree.
